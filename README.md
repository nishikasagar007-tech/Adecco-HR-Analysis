# ADECCO HR Analytics Project Dashboard

## Overview
This project presents an HR Analytics Dashboard built in Microsoft Excel using the HR-Employee-Attrition dataset. The workbook includes data cleaning, pivot table analysis, visual dashboards, and business insights to help understand employee attrition trends and workforce performance.

## Project Objectives
- Analyze employee attrition across different departments.
- Identify the key factors contributing to employee turnover.
- Evaluate job satisfaction, work-life balance, and training impact.
- Study overtime patterns and their relationship with attrition.
- Generate actionable HR recommendations based on data analysis.

## Workbook Structure

| Sheet Name | Description |
|------------|-------------|
| README | Project overview |
| Raw_Data | Original HR dataset |
| Basic_Analysis | Summary statistics and preliminary analysis |
| Department_Attrition | Attrition analysis by department |
| Gender_Attrition | Gender-wise attrition analysis |
| Job_Satisfaction | Job satisfaction analysis |
| Top_Attrition_Factors | Major factors influencing employee attrition |
| Overtime_Analysis | Overtime vs attrition analysis |
| Training_Impact | Training impact on employee retention |
| WLB_vs_Performance | Work-life balance vs performance analysis |
| Key_Insights | Business insights and recommendations |
| Dashboard | Interactive HR Analytics Dashboard |
